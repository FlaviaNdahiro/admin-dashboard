# Admin Dashboard

A responsive admin dashboard built using HTML and CSS.

## Features

- Sidebar navigation
- Dashboard header and admin profile
- Welcome section
- Statistics cards
- Sales analytics chart
- Recent orders table
- Responsive design for desktop, tablets, and mobile phones

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Git and GitHub

## How to Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
